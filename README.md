# fhw

## Contributing

> We use [pnpm](https://pnpm.io), an alternative to npm, to manage our packages.

Clone the repository and install dependencies:

```sh
git clone git@github.com:fourhundredwest/fhw
cd fhw

pnpm install
```

Start the development server:

```sh
pnpm dev
```

Format changes via [prettier](https://prettier.io):

```sh
pnpm format
```
